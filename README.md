# Irodori-TTS-Server-Installer

Windows用の非公式Irodori-TTS-Server簡易インストーラーです。

## v1.0.1

提供された `Irodori-TTS-Server-Installer-v1.0.1.zip` の10ファイルを、リポジトリ直下に保存しています。

1. このリポジトリをZIPでダウンロードし、すべて展開します。
2. `01_Install.bat` で導入します。
3. `02_Start.bat` でサーバーを起動します。
4. `05_Test_Speech.bat` で音声生成を確認します。

詳細は [README.txt](README.txt) を参照してください。

初期モデル: `Aratako/Irodori-TTS-v4-Large-Quantized/int8-weight-only`
